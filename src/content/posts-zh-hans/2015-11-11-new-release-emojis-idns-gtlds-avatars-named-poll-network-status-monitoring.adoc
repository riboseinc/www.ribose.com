= 擎威 Ribose 最新版本发布：表情符号、IDN/gTLD 支持、头像、命名投票、网络状态监控

大家好，

我们刚刚部署了最新版本，带来了许多错误修复以及期待已久的功能，包括：

* 表情符号（以及完整的 Unicode）支持：适用于所有文本，无处不在。一张图片胜过千言万语！

* 支持 IDN 和 gTLD 电子邮件地址：之前不支持包含非 ASCII 字符和国际域名的电子邮件地址，如 .在线、.みんな、.شبكة 或 .сайт。现在它们都被视为一等公民——与 ASCII 电子邮件地址相同。同样，我们现在支持帐户电子邮件中的所有有效 gTLD。

* 头像：用户和空间的默认头像现在使用他们名字的首字母。这使得用户能够在一定程度上轻松区分没有个性化头像的空间。当然，我们建议每个空间为用户设置描述性的头像！

* 命名投票：匿名和命名投票。之前只能发起匿名投票，我们收到了很多反馈，要求提供「命名投票」，允许在投票结果中显示谁投了哪个选项。现在，当您在创建投票时选择「投票匿名性 > 命名」时，就可以使用此功能。

* 网络状态监控：应用程序现在能够在网络离线时提供友好的提醒，告知用户此时所做的更改将不会被保存。

* 安全加固和性能提升：本次版本的主要改进集中在安全性加固和性能提升方面。

如有任何问题、反馈或一般性意见，请随时通过反馈表单或发送电子邮件至 support@ribose.com 与我们联系。

再次感谢您的支持！
