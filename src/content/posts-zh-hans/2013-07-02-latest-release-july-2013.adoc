= 擎威 Ribose 平台2013 年 7 月版本更新

本月初，我们释出了最新的擎威 Ribose 平台更新。

最显著的更新是全新的个人资料介面。我们使其更快速且更容易编辑和查看您的个人资料资讯。例如，您可以直接将滑鼠悬停并点击您的姓名进行编辑。之前，个人资料仅显示少数的联络人和空间，但现在我们显示更多，让您点击更少。

在讨论中，我们已将「评论」重新命名为「回复」，以回应即将推出的功能。我们还修复了许多错误，涉及以下方面：
即将推出的功能，敬请期待。

其他变更：

* 聊天介面修复与聊天错误
* 日历、档案、空间选单、小工具、指导/帮助、密码重设、电子邮件更改请求、邀请灯箱中的错误
* 通知小工具修复
* 维基：优化性能，修复错误
