= 擎威 Ribose 获得 Cloud Security Alliance APAC 年度安全创新奖

[香港] -- 2016 年 1 月 21 日 -- 擎威 Ribose 获得 Cloud Security Alliance (CSA) 年度安全创新奖，该组织是云端安全行业的顶尖机构。

Ribose 在 2015 年 12 月 3 日于中国广州举行的 CSA 亚太区首届颁奖典礼上获得该奖项，经评审委员会对专业性、卓越性、创新性和可衡量的成功进行仔细评估后，该奖项旨在表彰技术行业中的佼佼者，奖励在云端领域中具有创新性和卓越表现的组织。Ribose 与 Trend Micro 和 DBApp Security 一同被评为年度安全创新奖，表彰其在云端安全方面的真正创新方法。

Ribose 积极参与 CSA 的云端安全事务，其创办人 Ronald Tse 是 CSA 国际标准化委员会的成员，该委员会与多个合作伙伴（包括创建 ISO/IEC 27001 国际标准的信息安全管理系统的 ISO/IEC JTC1 SC27）一起制定与云端安全相关的国际标准。自 2013 年加入 CSA 以来，Ribose 已参与多个 CSA 研究计划，以促进和开发改进的云端安全实践，惠及用户和提供商。

由于这些努力，Ribose 拥有众多云端安全的「第一」成就，并积极参与多司法管辖区的云端安全计划，认为这些实践应成为行业标准，因为云端安全提供商（CSP）必须确保用户数据在地缘政治和监管边界上的安全。

擎威 Ribose 作为云端安全的先驱，是首家采用并推广 CSA 的 CCM 3 控制框架的 CSP，也是全球首家同时获得 CSA 三项云端安全评估计划认证的 CSP：STAR 认证（最高金级成熟度）、STAR 认证声明和 C-STAR 评估。Ribose 也是全球首家使用 CCM 3.0 和 CCM 3.0.1 获得 CSA STAR 认证和 STAR 认证声明的组织；同时也是首家获得 STAR 认证和 C-STAR 评估的软体即服务（SaaS）提供商。

云安全联盟首席执行官兼联合创办人 Jim Reavis 表示：「我们最初邀请 Ribose 加入 CSA，是因为看到他们致力于为用户提供最佳的安全保护。作为云端安全的先驱，Ribose 在追求用户安全保障方面引领行业，并成为全球首家同时获得 CSA 三项云端安全评估计划认证的组织：STAR 认证、STAR 认证声明和 C-STAR 评估。在评选 Ribose 为年度安全创新奖时，我们认可其为用户提供最高水平安全保护的奉献精神，以及通过与 CSA 的合作惠及整个云端安全行业的承诺。」


云安全联盟亚太区总经理兼国际标准化委员会秘书长 Aloysius Cheang 表示：「Ribose 作为亚洲 CSP 的领先典范，在用户安全和隐私方面树立了最佳实践。亚洲正迅速崛起为科技创新的下一个中心，像 Ribose 这样获得认证的世界级组织正在引领潮流。通过广泛使用 CCM 并协助其开发，Ribose 开创了一种高标准的云端安全方法——采用一个简化的流程，为所有用户提供强大的保护。」

擎威 Ribose 创办人 Ronald Tse 解释道：「获得这一认可对 Ribose 来说是一个极高的荣誉，因为我们与许多行业机构（如 CSA——云端安全的权威机构）密切合作。我们很高兴获得这一荣誉，这是对我们对云端安全的深厚承诺以及我们的方法和实施效果的外部证明。」

Tse 解释道：「CSA作为云端安全行业的标准机构，他们的研究对云端安全行业以及当今全球使用的几乎所有云端安全标准产生了强烈影响。作为 CSA 的企业会员和云端安全的领导者，我们强烈支持 CSA 的工作，并帮助他们制定和推动行业标准，从而提高全球云端提供商和用户的信心。」

「作为一个协作平台，Ribose 依赖最高水平的云端安全来保护我们用户的知识产权。知道他们的工作受到获奖、国际认证的安全水平保护，让我们的用户能够安心地专注于手头的任务，」Tse 总结道。
