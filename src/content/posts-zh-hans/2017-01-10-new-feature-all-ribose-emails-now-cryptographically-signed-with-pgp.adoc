= 新功能：所有擎威 Ribose 平台电子邮件现在都使用 PGP 进行加密签名

随著电子邮件钓鱼和欺骗行为日益普遍，许多人陷入了错误的绝望感。然而，有一些方法可以对抗这些行为，其中最常用的方法就是对电子邮件进行加密签名。

自上周起，Ribose 已经开始对所有发送给您的电子邮件进行 PGP 加密签名，以便您可以验证我们电子邮件的真实性。有效的 Ribose PGP 签名证明电子邮件在传输过程中未被修改，并且证明发件人确实是 Ribose，而不是恶意的第三方。

要验证电子邮件的 PGP 签名，目前需要安装某种插件，但大多数这些工具都能很好地与您的平台（Linux / macOS / Windows）集成。我们还在下面的 PGP 页面上列出了推荐的工具。

随著我们的许多用户来自敏感行业，其中一些人对加密电子邮件通知表示关注，以防止电子邮件中的数据泄露。作为下一步，我们将在即将发布的版本中启用电子邮件的全面加密，并提供上传您的公钥 PGP 的功能，该公钥将用于加密所有通过电子邮件发送的消息。敬请期待！
